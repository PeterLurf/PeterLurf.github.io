Endpoint self-report in looped language models

I injected concept vectors into each loop of a recurrent-depth model and asked it which sentence had changed. Subtracting a clean run recovers the injected sentence 96.9–100% of the time and a LoRA readout reaches 99.5%, yet the model's own answer stays at chance.
